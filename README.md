# Ground Station Link Monitor 📡

**Real-time link budgets, RF health monitoring and outage alerting for ground station networks.**

Part of the **Zion App Network — Batch 67 (Space & Satellite Ops AI)**: 840+ interconnected AI apps by [Zion Tech Group](https://ziontechgroup.com).

- Live link-budget computation per pass with weather and pointing corrections

- Outage and degradation alerts routed to ops channels
- Station utilization analytics feeding Satellite Pass Scheduler AI
- Historical pass replay for anomaly investigations
